GEAMS quick-start cards — print, cut, hand out. Fill in the web address in the blank.

🧑 Civilian

  1. Open __________________ and "Add to home screen".
  2. Sign up. Allow location. Read the privacy notice.
  3. Save your recovery code (Profile → Recovery code). You need it for a new phone.
  4. Emergency: press the big alert button, choose the type, send. Stay on the screen.
GEAMS does not replace calling 112. If nobody answers in a minute, call.

👮 Officer

  1. Register in the Dispatch app. Wait for the control room to approve you.
  2. Sign in. Change the first password when asked.
  3. Set status Available at start of duty.
  4. New job: read it, press Accept, then follow the route. Update status at each step.
  5. Face check: only on your own incident, only with a reason. Every check is logged. A match is a guide, never proof.
Forgot password? Ask your control room to reset it.

🚒 Fire crew

  1. Register in the Fire app, wait for approval, sign in, change the password.
  2. Accept the call the control room sends.
  3. Update status: on the way, on scene, finished.
  4. Need help from another service? Use Mutual aid.

🚑 Ambulance crew

  1. Register in the Ambulance app, wait for approval, sign in, change the password.
  2. Accept the call. Follow the route.
  3. Update status at each step.
  4. Need fire or police on scene? Use Mutual aid.

🏢 Control room (station)

  1. Sign in with the station passphrase and your own commander account.
  2. New alert rings: open it, check place and type, Assign a unit.
  3. Crew approvals: approve new crew, reset forgotten passwords, disable leavers.
  4. Resolve the incident when it is over. Add notes.
  5. Start of shift: check no old alerts are waiting.
You can only change your own station's records. If the system looks wrong, tell HQ and keep using the phone.

🏛 HQ owner

  1. Every day: Storage health (database OK? backup under 24 h?).
  2. Weekly: Face & ID checks log and Data retention preview.
  3. Problem: Lockdown. Leaked passwords: Rotate tokens.
  4. Keep the owner password and backup passphrase in two separate safe places.
Nobody can recover the backup passphrase for you.
